# NIRIKSHA - Working Demonstration

**Team:** DARSHAN 2.0
**Team Code:** A3-PS033-TC440
**Problem Statement:** PS-033 - DNS-Based Discovery of Diagnostic Services

## Watch the Working Demonstration

https://youtu.be/ceSasOSAdsU

This screen-recorded local experiment demonstrates:
- DNS-SD discovery and verification of a diagnostic service on port 8001.
- Controlled service failure while its discovery advertisement remains active.
- Detection of the unreachable endpoint.
- An advertised endpoint update to port 8002.
- Automatic discovery and verification of the replacement endpoint.
- Recorded telemetry, recovery measurements and an inspectable event timeline.

The test script controls the failure and advertisement update. The monitor independently discovers and verifies the endpoints.

The video uses AI-generated narration. Measurements describe the recorded experiment, not guaranteed performance. Operational verification is not a security or authenticity guarantee.

This link is a recorded working demonstration, not a hosted live application.
